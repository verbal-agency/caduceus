# Cycle handoff — G01 define domain contracts

**Status:** complete.

## Goal boundary

G01 adds Pydantic wire contracts for the bounded-agency flow: `Case`,
`Evidence`, `Claim`, `ProposedAction`, `AuthorizationRequest`, and
`AuthorizationDecision`. The contracts preserve synthetic-data-only handling,
structured deterministic authorization inputs, and evidence references without
introducing workflow transitions, authorization rules, persistence, execution,
or HTTP endpoints.

## Test-first evidence

`tests/test_domain_contracts.py` was added before `caduceus.domain` existed and
initially failed during collection with `ModuleNotFoundError`. After the model
implementation, the first red/green run exposed that model-wide strict parsing
rejects standard JSON arrays, enum strings, and ISO-8601 timestamps. The final
model forbids unknown fields and empty required identifiers while accepting the
canonical JSON wire representation required by the goal.

## Decisions and routed findings

- Pydantic is now an explicit direct dependency because the source specification
  requires Pydantic models; it was already available transitively through
  FastAPI.
- Contract validation intentionally does not decide whether an action is
  permissible. G07 owns deterministic authorization policy and outcomes.
- Case workflow state remains absent from `Case`; G02 owns the state enum and
  transition service.
- No incidental findings require a new backlog item or a roadmap reordering.

## Next goal
