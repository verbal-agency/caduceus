# Cycle handoff — G00 initialize the project

**Status:** complete.

## Goal boundary

G00 creates a runnable local Python service, a deterministic test foundation,
documentation, a synthetic-data guard, and initial adapter/ADR structure. It
does not implement healthcare domain models, agents, policy, authorization,
databases, external integrations, deployment, or user interface behavior.

## Test-first evidence

before the endpoint implementation. The initial test failed because
`caduceus.app` did not exist; `src/caduceus/app.py` then supplied the smallest
implementation that satisfies it.

## Decisions and observations

- Python 3.12 is the minimum supported interpreter. The available Python 3.10
  environment segfaulted during pytest capture initialization; this is recorded
  as a host-environment observation, not an application defect.
- FastAPI/Uvicorn establishes only the local HTTP shell. Adapter implementations
  remain intentionally empty and are owned by later goals.
- No fixture/example data has been added. The marker guard is a repository
  control, not a claim that an arbitrary data file is safe to commit.
